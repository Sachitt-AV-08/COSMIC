============================================================================================
  DESIGN PRINCIPLES
============================================================================================

  1.  Local-first       No cloud. No API keys. Your hardware, your data.
  2.  Composable        Each component works standalone. Combine for more power.
  3.  Agent-driven      AGNI creates, VEDA validates, VIJAY interacts, Planner executes.
  4.  Self-improving    TRISHUL learning loop: generate -> evaluate -> improve -> repeat.
  5.  Multi-accelerator CPU + GPU + iGPU + NPU -- right tool for each job.
  6.  Secure            Tool safety model. Vault. MFA. Audit chain. No blind trust.
  7.  Beautiful         Dark cosmic theme. Glowing nodes. Clean UI across all projects.
  8.  Functional        ~296,000 lines of real, working code. Not stubs.
